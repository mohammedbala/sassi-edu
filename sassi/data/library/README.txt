SASSI-EDU built-in input library
================================

Standard inputs that ship with the program, so that a model can be analysed
before the project-specific inputs exist.  Refer to a file with the prefix @
anywhere a file name is read, for example

    THFILE,@rg160h_030g.acc
    RSIN,1,@rg160h_030g.rsi
    INP,@dynp_library.pre

The command LIBRARY lists the files (LIBRARY,DEFAULTS shows the defaults the
active model uses).  Several of them are also the defaults of blank inputs
(requirements section 7.19, decisions D-W5-01 ... D-W5-14); every default that
is used is reported by CHECK (Warning EDU-29), AFWRITE and the module run.
EDUOPT,DEFAULTS,OFF switches the defaults off (ACS SASSI behaviour: the inputs
are required).  The @ names themselves always work.

The files are read-only copies.  Their originals are kept elsewhere in the
project (examples/data, sassi/data/rg160, sassi/data/dynp_library.pre); a unit
test checks that the copies are identical.

Files
-----

rg160h_030g.acc
    Kind: acceleration record (THFILE / ACCIN / SOILX file), MOTION <fopt> 0
    layout: line 1 the time step, then one value per line.
    Units: g.  dt = 0.005 s, 4001 values (20 s), PGA 0.324 g.
    Source: generated by SASSI-EDU EQUAKE (seed 11975, 5 % damping) to match
    the RG 1.60 horizontal spectrum anchored to 0.30 g (rg160h_030g.rsi);
    copy of examples/data/rg160h_030g.acc, the control motion of the
    examples.  An educational record, not a site-specific design motion.
    Default of: THFILE (seismic analyses: ANALYS <type> 0, and SOIL).

rg160h_030g.rsi
    Kind: target response spectrum (RSIN).  Two columns: frequency (Hz),
    spectral acceleration (g); 27 rows, 0.1 - 100 Hz, 5 % damping.
    Source: US NRC Regulatory Guide 1.60 horizontal design spectrum anchored
    to 0.30 g (sassi.core.equake_lib.rg160_spectrum; = 0.30 x rg160h_1g.rsi).
    Default of: RSIN 1 (EQUAKE, when no RSIN file is given; <nrfreq> = 27).

rg160h_1g.rsi, rg160v_1g.rsi
    Kind: target response spectra (RSIN).  Frequency (Hz), SA (g); 27 rows,
    0.1 - 100 Hz, 5 % damping, anchored to 1.0 g: scale linearly for another
    peak ground acceleration.
    Source: RG 1.60 horizontal / vertical design spectra; copies of
    sassi/data/rg160/RG160H_5pct_1g.rsi and RG160V_5pct_1g.rsi.  The rows
    include every RG 1.60 control point (0.25, 2.5, 3.5, 9, 33 Hz).

rg160h_030g_cm2s3.tpsd, rg160h_030g_in2s3.tpsd
    Kind: target power spectral density (TPSD).  Frequency (Hz), one-sided
    PSD in cm^2/s^3 (SI models, gravity 9.81) or in^2/s^3 (British models,
    gravity 32.2); 124 rows, 0.05 - 100 Hz.
    Source: SRP 3.7.1 Rev. 4 Appendix A minimum PSD for the RG 1.60
    horizontal spectrum, scaled to 0.30 g (factor 0.30^2 = 0.09;
    sassi.core.equake_lib.rg160_target_psd).  Use with rg160h_030g.rsi.

rg160h_appa_1g_cm2s3.tpsd, rg160h_appa_1g_in2s3.tpsd
    Kind: target power spectral density (TPSD), as above at 1.0 g (scale by
    PGA^2).  Copies of sassi/data/rg160/RG160H_AppA_1g_*.tpsd.  SRP 3.7.1
    Appendix A defines no vertical target PSD.

ricker_5hz.th
    Kind: load history (THFILE of a forced-vibration analysis, ANALYS <type> 1),
    MOTION <fopt> 0 layout.  Units: load factor (dimensionless, peak 1.0);
    the FORCE amplitudes give the force units.  dt = 0.005 s, 401 values (2 s),
    a 5 Hz Ricker wavelet, peak 1 at t = 0.5 s.
    Source: SASSI-EDU (example 3, examples/data/ricker_5hz.th).
    Default of: THFILE (forced-vibration analyses: ANALYS <type> 1).

dynp_library.pre
    Kind: strain-dependent soil curves (DYNP commands; labels Clay, Sand, Rock).
    Strain in %, G/Gmax, damping in %.
    Source: SHAKE91 sample input INP.DAT (Idriss & Sun 1992, public domain):
      Clay  Seed & Sun (1989) upper range / Idriss (1990) damping
      Sand  Seed & Idriss (1970) upper range / Idriss (1990) damping
      Rock  Schnabel (1973) average
    Copy of sassi/data/dynp_library.pre.
    Default of: the DYNP labels Clay, Sand and Rock when the model does not
    define them (a model DYNP of the same label wins), and the labels of the
    default SOIL profile (no SPRO given: Sand for Vs < 760 m/s or 2493 ft/s,
    Rock above).
