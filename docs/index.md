# SASSI-EDU documentation

SASSI-EDU is an educational Python re-implementation of the SASSI flexible-volume method of
soil-structure interaction analysis, with the module, command and file nomenclature of the ACS
SASSI Version 3 user manual. It is not affiliated with, endorsed by, or a substitute for ACS SASSI,
and it is not qualified for licensing or design work.

Like the commercial program, SASSI-EDU comes with three manuals: a user manual, a theory basis and a
verification and validation manual.

## The manuals

| Document | What it contains | Read it when |
|---|---|---|
| [User Guide](user/USER_GUIDE.md) | installation, console, batch and GUI use; the SSI workflow and module chain; the command language; structure, site, excavation and interaction nodes; frequencies; ANALYS; post-processing; ANSYS models and the two-step approach; advanced options (incoherency, 2D, symmetry, nonlinear soil, SOIL-NON, Option NON, water, TSHELL, AFWRBAT); common errors; engineering guidance; the tutorial examples; ACS SASSI term mapping; limitations | you want to build and run a model |
| [Theory Manual](theory/THEORY_MANUAL.md) | complex-modulus damping, flexible-volume substructuring, thin-layer method, half-space, free field, POINT central zone and transmitting boundary, impedance, Schur-complement solution, interpolation, convolution and spectra, SHAKE, elements (TSHELL, node optimizer), incoherency and wave passage, 2D SSI and symmetry, nonlinear soil iterations, Option NON, SOIL-NON, water, Option A, EQUAKE; each section with its code and its verification problems | you want to know what the program computes and why |
| [Verification Manual](verification/VERIFICATION_MANUAL.md) | every verification problem with its model, reference, computed values, errors, tolerances and result; the module coverage matrix; the lead decisions on superseded references | you want to know how far the results can be trusted |
| [Command Reference](reference/COMMAND_REFERENCE.md) | every command with syntax, abbreviation, tier and implementation status | you look up a command |

The Verification Manual and the Command Reference are generated by `sassi/verify/report.py`
(`.venv/bin/python -m sassi.verify.report`, or `--commands-only` for the Command Reference); do not
edit them by hand.
